# TalkSync - Intelligent Networking Chatbot 🚀

TalkSync is a sleek, real-time chat application built using **Node.js**, **Express**, and **WebSockets**. It features an intelligent built-in virtual assistant, **NPS Bot**, that specializes in answering network protocol-related queries. 

The application utilizes a dark cybersecurity-themed aesthetic, ensuring a highly engaging and modern user experience!

## ✨ Features
- **Real-Time Communication**: Instant, bi-directional messaging using WebSockets.
- **Intelligent Chatbot (NPS Bot)**: Understands and responds to queries related to TCP, UDP, IP, DNS, HTTP, HTTPS, OSI Model, and more!
- **Sleek UI**: Cyber-themed background with modern typography (Orbitron & Segoe UI).
- **Asynchronous Replies**: The bot simulates a natural thinking process with a realistic delay before responding.

## 🛠️ Technology Stack
- **Backend**: Node.js, Express.js
- **Real-time Protocol**: WebSockets (`ws` library)
- **Frontend**: HTML5, CSS3, Vanilla JavaScript

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone https://github.com/karthikchowdary13/Chat-Application.git
   cd Chat-Application/chat-websocket-app
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start the server**:
   ```bash
   node server.js
   ```

4. **Open the App**:
   Visit [http://localhost:3000](http://localhost:3000) in your web browser.
